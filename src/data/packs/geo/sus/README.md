# OpenStreetMap geometry – sus

Not fetched yet. Until `.github/workflows/fetch-osm.yml` has run for this pack, the app and the tests use the hand-made fixture files in this directory (`fixture.json`, `fixture-streets.json`, `fixture-power.json`, `fixture-water.json`), which have the same schema as the files `scripts/fetch-osm.mjs sus` writes. The fixture's names are the real names of the roads, interchanges and substations; its numbers are invented. It is regenerated by `node scripts/make-geo-fixtures.mjs sus`.

Planned data: OpenStreetMap via the Overpass API (https://overpass-api.de/api/interpreter), queries in `scripts/overpass/sus/`, bounding box 55.35, 12.80, 55.95, 13.75, streets within 2 500 m of each of the 16 zone centres. Size budgets: roads 4 096 KB, streets 2 560 KB, power 512 KB.
